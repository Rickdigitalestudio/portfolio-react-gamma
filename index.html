Responsabilidade única
Cada componente faz uma coisa bem feita. Se passou de ~150 linhas, provavelmente virou dois.

                        
Props descem, eventos sobem
Dados fluem de cima para baixo; ações voltam por callbacks. Sem isso, você recria o prop drilling na marra.

            05 · Estado & efeitos
            
Hooks: playground funcional de verdade

            
Não é print de código: os demos abaixo são React-like rodando aqui mesmo. Interaja e veja o estado mudar.

            

                

                    
useState
estado local

                    
Contador com estado imutável — cada clique re-renderiza só o que precisa.

                    

                        
                        0
                        
                        
                    

                    
const [n, setN] = useState(0)
setN(prev => prev + 1) // sempre via updater

                

                

                    
useEffect
efeitos colaterais

                    
Simula uma chamada de API com loading, dados e erro — o ciclo completo.

                    

                        
                        
Idle — aguardando ação

                    

                    
useEffect(() => {
  carregar()
}, [/* deps */]) // [] = só ao montar

                

                

                    
useContext
estado global

                    
Tema compartilhado sem prop drilling — muda a UI do demo na hora.

                    

                        
Texto de exemplo dentro do provider.

                        
                    

                    
const tema = useContext(ThemeContext)
<Provider value={tema}>

                

            

            

                
useMemo
Memoiza cálculos pesados (filtrar 500 projetos) para não recomputar a cada render.

                
useCallback
Estabiliza funções passadas como props — essencial quando filhos recebem React.memo.

                
useRef
Acessa o DOM sem causar render: focar input, medir altura, scrollar até a seção.

                
useNavigate
Roteamento programático no React Router — redireciona após login ou envio de formulário.

            

            
Regra de ouro: chame Hooks sempre no mesmo ordem, no topo do componente — dentro de if, for ou callback eles quebram o contrato do React.

            07 · Qualidade
            
Performance e SEO: os Core Web Vitals

            
Metas do Google para um site saudável. Passe o mouse sobre os medidores para ver como melhorar cada um.

            

                
LCP< 2,5s
Imagens em WebP/AVIF, fontes com font-display: swap e HTML estático no CDN.

                
CLS< 0,1
Reserve espaço com aspect-ratio e nunca insira banner acima do conteúdo sem altura fixa.

                
INP< 200ms
Evite tasks longas no main thread; use startTransition para atualizações não urgentes.

Erros que fazem o portfólio ser ignorado

            

                
    
                    
  • Projeto "to-do list" sozinho — mostre 1 app completo, não 10 tutoriais iguais.
    • 
                    
  • Textos genéricos — "apaixonado por tecnologia" não diferencia ninguém.
    • 
                    
  • Site lento ou quebrado no mobile — motivo nº 1 de bounce.
    • 
                    
  • Link morto no README — teste o deploy em aba anônima antes de enviar.
    • 
                

                
    
                    
  • Estudo de caso por projeto — contexto, decisões, resultado.
    • 
                    
  • Números reais — "de 4s para 1,2s de LCP" vale mais que "otimizado".
    • 
                    
  • Sobre você com personalidade — foto, stack, o que te move.
    • 
                    
  • CTA óbvio — e-mail/LinkedIn visível no topo e no rodapé.
